# Glossário

Use este arquivo para impedir que termos importantes tenham significados diferentes entre Product, UX, Arquitetura, PM e QA.

| Termo | Definição aprovada | Sinônimos proibidos ou observações | Fonte |
|---|---|---|---|
| `Epic` | Resultado ou capacidade ampla que será decomposta em stories relacionadas. | Não é uma lista de tasks. | A preencher |
| `Story` | Unidade vertical de valor para uma persona, com comportamento observável e critérios de aceitação. | Não é uma tarefa técnica isolada. | A preencher |
| `Task` | Unidade de trabalho executável, com resultado verificável e dependências explícitas. | Deve caber em uma sessão de execução razoável. | A preencher |
| `Ready` | Estado no qual o item tem contexto e informações suficientes para execução/revisão. | Não significa que já foi implementado. | `docs/04-pm-stories/README.md` |
| `DoD` | Definition of Done: condições globais para considerar a entrega concluída. | Não substitui critérios de aceitação. | `docs/04-pm-stories/definition-of-done.md` |

Adicione termos do domínio assim que o Product Brief for recebido.
